# Практическая работа №3 (Lab_3)

## Условия задач

### Задача A1
Вводятся координаты двух точек на плоскости: x1, y1, x2, y2. Все координаты не равны 0. Определить, лежат ли обе точки в одной координатной четверти. Если да, то определить в какой четверти лежат точки.

### Задача A2
Программа проверяет введенный пароль на надежность. Требования: длина — 8 символов; заглавные и строчные буквы, цифры, спецсимволы `*, -, #`. Выводит слово «Надежный пароль» или список всех допущенных ошибок.

### Задача A3
Расчет счета за газ по дифференцированному тарифу на основе предыдущего и текущего показаний круглого счетчика (с ограничением до 9999 и сбросом на 0). Вывод в виде таблицы с округлением стоимости до двух знаков после запятой.
