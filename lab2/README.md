## Краткое описание выполненных заданий

* А1 (Выражения): Расчет значений и определение типов данных для базовых арифметических операций.
* А2 (Функция int): Анализ работы функции приведения типов `int()` и разбор ошибок `ValueError`/`TypeError`.
* А3 (Память): Программа вычисления размера гигантского числа 3⁹⁰⁹⁰⁰⁰¹ в мегабайтах с проверкой через системный модуль `sys.getsizeof()`.
* А4 (Наибольшее число): Поиск максимума из двух чисел без использования стандартного ветвления `if-else` (с помощью тернарного оператора / списков).
* А5 (Делимость): Проверка делимости числа A на B нацело без использования `if-else`.
* А6 (Электронные часы): Конвертация прошедших с начала суток секунд в формат времени `h:mm:ss` с использованием метода `.format()`.
* А7 (Шахматная доска): Определение цвета двух клеток по их координатам и проверка их на совпадение без использования ветвлений.

## Как запустить проект
1. Поместить файлы входных данных в корневую папку.
2. Запустить нужный скрипт через терминал, например: `python a6.py`
